# Quiz Game

This is a small quiz game I made while practicing JavaScript.

The game starts with a start button, and after starting, it shows questions one by one. After answering all the questions, it calculates the score and shows the final result along with a message based on the percentage.

## Features

* Start the quiz
* Display questions one by one
* Select answers
* Calculate the final score
* Show score percentage
* Display a message based on the result

## Result Messages

* **100%** → Perfect! You're a genius!
* **80% or above** → Great job! You know your stuff!
* **60% or above** → Good effort! Keep learning!
* **40% or above** → Not bad! Try again to improve!
* **Below 40%** → Keep studying! You'll get better!

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Click **Start Game** and begin the quiz.
